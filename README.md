# Stick Duel

Stick-figure archery for phones and tablets (play in landscape).

- **index.html**: Stick Duel Versus. One device taps **HOST GAME** and gets a 4-letter code; the other taps **JOIN GAME** and enters it. Best of 3 rounds. Or practise against the bot.
- **solo.html**: the full single-player game: levels, bosses, weather, hanging windows and fans, special arrows and a shop.
- **coop.html**: Stick Duel Co-op. The single-player game for a team on 2 or more devices. One player hosts and gets a 4-letter code; everyone else joins with it (friends can also join after the game starts). Players stand at random spots, each earns and spends their own GP, arrows can hit teammates, and a player who goes down can look around and mark targets until the next level.

Share the game with the **SHARE GAME** button, or tap **ADD TO HOME SCREEN** to get a Stick Duel icon that opens the game in one tap. In co-op the host can tap **INVITE FRIENDS** to send a link that already has the game code in it, or friends can scan the QR code.

To play locally, open either file in a browser. Versus and co-op need an internet connection, and both devices on the same Wi-Fi is most reliable.

See `CLAUDE.md` for how the game works and how to develop it.
