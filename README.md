# Stick Duel

Stick-figure archery for phones and tablets (play in landscape).

- **index.html**: Stick Duel Versus. One device taps **HOST GAME** and gets a 4-letter code; the other taps **JOIN GAME** and enters it. Best of 3 rounds. Or practise against the bot.
- **solo.html**: the full single-player game: levels, bosses, weather, hanging windows and fans, special arrows and a shop.

To play locally, open either file in a browser. Live versus needs an internet connection, and both devices on the same Wi-Fi is most reliable.

See `CLAUDE.md` for how the game works and how to develop it.
